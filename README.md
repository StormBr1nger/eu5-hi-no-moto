# Hi no Moto: Realm of the Rising Sun

**Hi no Moto** is a historical grand-strategy project focused on Japan’s political, military, cultural, and dynastic development from the medieval era through alternative historical futures.

## Current Phase

**Phase 1: Project Foundation**

## Core Identity

- Short title: **Hi no Moto**
- Full title: **Hi no Moto: Realm of the Rising Sun**
- Genre direction: historical grand strategy
- Main focus: Japan-centered political, military, and dynastic simulation
- Player fantasy: rule, survive, unify, reform, or reshape the realm
- Core themes: clan power, imperial legitimacy, shogunate authority, warfare, culture, and alternative history
